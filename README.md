# Core Belief ORB

A browsable educational map of short assumptions, protective rules, and identity across five overlapping learning contexts: social convention, conditional belonging, persistent stress, traumatic threat, and coercive influence.

The reading edition contains 41 linked points, including 25 original hypothetical belief examples, six explanatory mechanisms, and four knowledge-floor readings. The framework is an authorial synthesis, not a validated assessment or severity scale. Examples are not quotations, diagnoses, or evidence about a visitor's personal history. Source records specify their scope.

Open `index.html` in a browser. It is self-contained: map, search, compass, readings, and continuation work without a network connection. Source and directory links require the internet. Copying may require manually selecting the visible text in browsers that restrict the clipboard for local files.

- Use the context buttons or **Find a belief** to select a reading.
- UP/DOWN move between broader frames and deeper explanation; LEFT/RIGHT visit adjacent facets.
- FORWARD/BACKWARD follow the labeled explanatory thread. **Previous visit** follows browsing history separately.
- Arrow keys operate the spatial compass; `[` and `]` operate the explanatory thread.
- **Print this point** prints the reading with its sources.
- **Jump into Orbiverse** provides a copyable continuation and an optional JSON checkpoint for another conversation.

No audio, AI connection, analytics, personal notes, or automatic progress storage is included. Browser history may retain visited URLs. Reduced-motion preferences stop automatic rotation; rotation can also be paused manually.

`orb.json` is the structured source data; the same data is embedded in `index.html`. `readings.md` contains the complete textual edition. Authored by the primary assistant, September 9, 2026.
